# 속성 상성 · 역할 패시브

단일 타워의 **속성**과 4역할 **패시브**가 전투에 반영됩니다.  
코드: `js/gameDemo.js` — `ELEMENT_SUPER`, `ROLE_PASSIVE`, `applyPassiveDamageMods()`

---

## 1. 속성 (단일 역할만)

- 타워: `getElementForUnit(baseId, 'single')` → 8속성 중 1개
- 적: 스폰 시 `pokemonId % 8` 로 동일 8속성 부여 (`enemy.element`)

### 상성 배율

| 결과 | 배율 | 상수 |
|------|------|------|
| **효과적** | ×1.35 | `TYPE_SUPER_MUL` |
| **약함** | ×0.75 | `TYPE_WEAK_MUL` |
| 보통 | ×1.0 | — |

### 효과적 (공격 → 방어)

| 공격 | 강함 |
|------|------|
| 불 | 풀, 얼음 |
| 물 | 불 |
| 풀 | 물 |
| 전기 | 물 |
| 얼음 | 풀, 드래곤 |
| 에스퍼 | 악 |
| 드래곤 | 드래곤 |
| 악 | 에스퍼 |

### 약함 (공격이 약한 방어 속성)

| 공격 | 약함 |
|------|------|
| 불 | 물 |
| 물 | 풀, 전기 |
| 풀 | 불, 얼음 |
| 전기 | 풀 |
| 얼음 | 불 |
| 에스퍼 | 악 |
| 드래곤 | 얼음 |
| 악 | — |

범위·슬로우·버프는 속성 없음 → 상성 미적용.

---

## 2. 역할 패시브

| 역할 | 패시브 | 효과 |
|------|--------|------|
| **단일** | 속성 상성 | 위 표 적용 (유일) |
| **범위** | 스플래시 강화 | 주변 스플래시 데미지 **×1.12** (`AOE_PASSIVE_SPLASH_MUL`) |
| **슬로우** | 강화 감속 | 감속 **2.3초**, 속도 **×0.42** (기본 1.8초·×0.5) |
| **버프** | 버프 광역 | 버프 타워의 버프 사거리 **+28px** (기본 120) |

버프·슬로우·범위 패시브는 `resolveAttackHit` / `getBuffReachRadius` / `applyAoeSplashAt` 에서 처리.

---

## 3. 데미지 계산 순서

```
기본 공격력 (단계×역할×등급×개체)
  → × 버프 스택 (getBuffMultiplier)
  → × 속성 상성 (단일 + 대상 적 있을 때)
  → × 범위 직격 (범위 역할 시 AOE_PASSIVE_HIT_MUL, 선택)
  → 적 HP 차감
```

범위 **스플래시**만 1.12배 (직격은 기존과 동일).
